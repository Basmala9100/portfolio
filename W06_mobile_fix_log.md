# Week 6 — Portfolio Fix Log

## Mobile Testing

I tested my portfolio on a real mobile phone instead of only
resizing the desktop browser.

### Fix 1 — Navigation

**Before:**
The navigation links were too close together on a small screen,
which made them difficult to tap.

**After:**
I increased the spacing between the navigation links and adjusted
the layout for smaller screens.

---

### Fix 2 — Profile Image

**Before:**
The profile image was too large on mobile and took up too much
vertical space.

**After:**
I reduced the image size and made it responsive so it scales
properly on smaller screens.

---

### Fix 3 — Project Layout

**Before:**
The project sections were not optimized for a narrow screen and
some content had uncomfortable spacing.

**After:**
I adjusted the layout and spacing so the projects fit within the
mobile viewport.

---

### Fix 4 — Text Readability

**Before:**
Some text was too small or had insufficient spacing on mobile.

**After:**
I increased the readable text size and adjusted line height and
spacing between sections.

---

### Fix 5 — Contact Form

**Before:**
The contact form was not checked on a real mobile device.

**After:**
I tested the form on mobile and confirmed that the fields and
submit button are usable on a small screen.
